# Hi, I'm Raúl

I'm a web developer at [Pululart](https://pululart.com), where I've been building and maintaining production web apps since 2022. At work the frontend is mostly React and Next.js with TypeScript. On the backend I've mostly switched from Node to Bun, usually with Elysia and Drizzle.

Outside work, these days I'm writing a lot of [Crystal](https://crystal-lang.org). I like how it feels like Ruby but compiles to fast native code. For frontend side projects I usually reach for SvelteKit, and sometimes Astro.

I also like handling what comes after the code: setting up servers, vhosts, SSL and keeping processes running on CloudPanel and Plesk. A lot of my repos came out of that work. They're small helpers and extensions for things those panels don't do on their own, like running Bun.

Before web I worked on Android apps with Kotlin.
